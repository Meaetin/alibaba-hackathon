The `src/lib` directory is a flat collection of feature-scoped sub-packages (`api`, `auth`, `errors`, `maps`, `motion`, `planner`, `query`, `supabase`, `utils`) plus shared root files (`domain-types.ts`, `site.ts`, `selection-style.ts`, `utils.ts`). Cross-child wiring happens through these root artifacts: `domain-types.ts` defines the canonical `Surface`, `ShareableEntity`, and `QuotaType` enums that every child module imports so analytics, sharing, and quota logic stay consistent; `site.ts` exposes a single `SITE_URL` origin used by both server-side metadata and client-side links; `query/queryClient.ts` and `query/queryKeys.ts` provide the global React Query client and key factory that `supabase_layer` and `api_clients` consume to cache data uniformly. Children communicate indirectly via this shared contract layer rather than importing each other directly — e.g., `planner_engine` consumes place data produced by `maps`, while `api_clients` and `supabase_layer` both publish typed results into the same React Query cache keyed by the shared `queryKeys`. The `auth/password-policy.ts` and `errors/` modules are leaf utilities imported by multiple children without owning state.
