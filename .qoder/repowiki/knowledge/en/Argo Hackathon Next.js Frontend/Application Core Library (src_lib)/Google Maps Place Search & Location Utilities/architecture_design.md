The module is a flat collection of single-purpose helpers with no runtime framework dependency beyond `google.maps` types. `place-search.ts` is the central piece: it defines the normalized `PlaceSearchResult` shape, field masks (`BASE_FIELDS`, `ENTERPRISE_EXTRAS`, `SEARCH_FIELDS`) that drive billing-aware requests to the Maps JS `Place.searchByText` / `searchNearby` APIs, and functions `runPlaceSearch`, `fetchPlaceDetailsEnterprise`, `normalizePlace`, `toPlaceDetailsPayload`, and `placeNeedsDetails` that bridge between the raw Places JS response and the server's `locations` schema. `price-level.ts` provides a shared `PriceLevelOrdinal` type and `toPriceLevelOrdinal` normalizer so both browser and server agree on budget filtering regardless of whether the source is Maps JS (`MODERATE`) or REST (`PRICE_LEVEL_MODERATE`). `locality-pins.ts` groups saved locations into string-based `{region}, {country}` clusters for static maps, explicitly separated from the planner's k-means geographic clustering. `location-row.ts` adapts persisted `ResolvedGoogleMapsLocation` rows back into `PlaceSearchResult` for the Add Location form. `google-maps-url.ts` is a tiny host-pattern validator for Google Maps share links. Dependency direction is one-way: `place-search.ts` imports `price-level.ts`; other files depend on `place-search.ts` only via types or the `PlaceSearchResult` interface.
