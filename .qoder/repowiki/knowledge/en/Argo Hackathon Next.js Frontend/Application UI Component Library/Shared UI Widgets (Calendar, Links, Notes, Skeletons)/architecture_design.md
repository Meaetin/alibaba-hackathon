The module groups four independent widget sub-packages under `src/components/ui/`, each focused on a single visual domain:
- `calendar/` — A small calendar system centered on `ActivityTimeslot.tsx`, which defines the shared `CalendarActivity` type and a palette engine (`DAY_PALETTES`, `getDayPalette`, `PALETTE_COLORS`, `getDayColor`) that maps day indices to CSS custom properties (`--cal-{name}-bg/marker/fg`) and hex colors for dark/light themes. `DaysTab.tsx` renders a collapsible day-filter menu via `@/components/ui/primitives/Menu`, and `ItineraryCalendar.tsx` re-exports the `CalendarDay` interface used by parent components.
- `links/LinkQueueCard.tsx` — A stateful card driven by `class-variance-authority` variants (`default|hover|processing|queued|failed`) that composes primitives (`Button`, `CategoryBadge`, `ProgressBar`) and exposes an accessible, keyboard-navigable surface with thumbnail, footer, progress bar, and retry/remove actions.
- `notes/InlineNoteEditor.tsx` — Two exported components: `NoteCardGrid` (a responsive grid of read-only activity notes plus standalone notes and a 'New Note' tile) and `NoteEditor` (an auto-save editor with debounced persistence, back/delete controls, last-edited timestamp formatting, and a `ConfirmActionDialog`). State is local; mutation is delegated through `onSave`/`onDelete`/`onClear` callbacks, and a `backRef` lets parents trigger save-and-back from outside.
- `skeletons/` — Lightweight placeholder components (`CardGridSkeleton`, `FilterToolbarSkeleton`) re-exported from `index.ts`, built with Tailwind's `animate-pulse` and design tokens to mirror real layout structure during loading.

Dependency direction is one-way: widgets import shared primitives from `@/components/ui/primitives/*` and utilities from `@/lib/utils`; there are no cross-imports between the four sub-packages, keeping them independently consumable.
