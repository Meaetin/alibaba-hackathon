The module is a React client component tree rooted at `Navbar.tsx`, which composes smaller sub-components: `NavbarSearchBar` (input + scan button), `FilterPill`/`FilterChip` (active-type filters), `SearchDropdown` (recent items, type filters, paginated results via `SearchResultCard`), `NewMenuDropdown` (create Link/Collection/Itinerary), and `NavbarProfileMenu` (settings/billing/sign-out). `Navbar` owns all search state (`searchActive`, `searchQuery`, `searchOffset`, `accumulatedResults`) and data fetching through hooks from `@/hooks/queries` (`useRecentlyViewedQuery`, `useSearchQuery`, `useEntityLocationsQuery`), while filter context comes from `@/contexts/NavbarFilterContext`. The search overlay is rendered via `react-dom`'s `createPortal` into `document.body` to escape the navbar's `isolate` stacking context, positioned absolutely using an anchor ref measured by `useLayoutEffect`. Desktop vs mobile layouts are split by `useBreakpoint` (`isDesktop`), with mobile collapsing actions into a `Menu` primitive. All UI primitives (`Button`, `NavTabs`, `Menu`, `CategoryBadge`) and shared motion presets live under `@/components/ui/primitives` and `@/lib/motion/presets`; this module only re-exports `Navbar` through `index.ts` as the public entry point.
