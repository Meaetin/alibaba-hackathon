Flat collection of self-contained React client components under a single directory, each exporting one component plus its props type. Components are split by domain: itinerary item cards (`FlightCard`, `LodgingCard`, `TransactionCard`, `ExpenseSummaryCard`), per-domain sidebars (`FlightSidebar`, `LodgingSidebar`, `ExpensesSidebar`) that compose the corresponding card and empty/loading states, and detail views (`LocationDetailView`, `FlightDetailsSection`, `FlightRouteSection`). Forms (`FlightForm`, `LodgingForm`) use local state and submit via callbacks to callers. Cross-cutting helpers (`AlsoInCard`, `OpeningHoursAccordion`, `PanelEmptyState`, `PanelFooterCTA`, `FilePillHeader`, `NotesGrid`, `TypeableTimePicker`, `LocationHoverDetailsPopup`) live alongside and are reused across domains. Data fetching is delegated outward — `LocationDetailView` uses `useLocationReferencesQuery` from `@/hooks/queries` and `@tanstack/react-query`, while other components receive data as props. UI primitives (Menu, Button, Popover, Sheet, Calendar, SearchBar, Separator) are imported from `@/components/ui/primitives`, and layout/styling rely on `cn` from `@/lib/utils`. Heavy or browser-only features (e.g., `StaticMap`) are loaded via `next/dynamic` with `ssr: false`.
