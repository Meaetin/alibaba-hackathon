The module is a flat collection of self-contained React component files under `src/components/ui/modals/`, each exporting one or more presentational components built on top of `@base-ui/react/dialog` (or a custom portal). Two architectural tiers are visible: (1) shared primitives — `FormModal.tsx` provides a generic form-backed dialog with variant-driven icon rings/circles (`cva`-based `formModalIconRingVariants` / `formModalIconCircleVariants`), mobile sheet behavior via `useBreakpoint`, and a submit/cancel button pair; `ConfirmActionDialog.tsx` offers a generic confirmation dialog with an alert header. (2) domain-specific consumers — `NewCollectionModal`, `NewItineraryModal`, `NewLinkModal`, `NewLocationModal`, `AlsoFoundInModal`, `AddToDestinationModal`, `InviteModal`, `FeedbackModal` compose `FormModal` to render their specific forms, while destructive flows (`ConfirmDeleteModal`, `DeleteAccountDialog`) build their own `Dialog.Root`/`Dialog.Portal` layouts with escalating confirmations (simple delete vs typed DELETE phrase plus impact summary). `ImageGallery.tsx` is independent of Base UI and renders a full-screen lightbox via `react-dom/createPortal` into `document.body`. All components are Next.js client components, depend only on shared primitives in `@/components/ui/primitives/*` (Button, Input, Separator, Pill, PlaceAutocomplete), styling utilities (`cn`, `class-variance-authority`), and `lucide-react` icons — no cross-modal imports exist between sibling files, keeping each modal independently composable by callers.
