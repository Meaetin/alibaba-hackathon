Two sibling sub-packages under `src/components/ui/` share a common design-system foundation but serve different concerns. The `auth/` folder provides form primitives built on top of the app's primitive layer: `AuthButton` wraps `@/components/ui/primitives/Button`, `GoogleAuthButton` uses `@base-ui/react/button` directly, and `AuthInput` composes `@base-ui/react/field` with motion-driven clear/trailing icons; `PasswordRequirements` reads rules from `@/lib/auth/password-policy`. All components are client-side (`"use client"`) and styled via Tailwind utility classes combined through a shared `cn` helper from `@/lib/utils`. The `StripeBackground/` folder is a self-contained visual component that injects a single `<style>` keyframe into `document.head` via `useInsertionEffect` to animate a repeating diagonal stripe pattern, resolving colors from hex, CSS variables, or Tailwind v4 color names. Dependency direction is one-way: these UI components depend on shared primitives, utilities, and motion presets but expose no internal APIs beyond their exported React components and types.
