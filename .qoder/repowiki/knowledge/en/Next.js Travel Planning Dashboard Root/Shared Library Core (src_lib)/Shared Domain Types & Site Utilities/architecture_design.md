This leaf module is a flat collection of small, independent utilities with no internal dependencies between its files. `domain-types.ts` defines string-literal union types (`Surface`, `ShareableEntity`, `QuotaType`) that model cross-cutting domain concepts such as UI surfaces and shareable resources. `site.ts` exposes a single normalized `SITE_URL` constant derived from the `NEXT_PUBLIC_SITE_URL` environment variable (falling back to `http://localhost:3000`), intended for metadata base URLs and Open Graph tags. `utils.ts` re-exports a `cn` helper built on `clsx` + `tailwind-merge` for deterministic Tailwind class concatenation. `selection-style.ts` centralizes visual style tokens (`rubberBand`, `unselected`) and exports pure functions (`rubberBandStyle`, `unselectedCardStyle`) that compute React/JSX style objects from geometric or default inputs. All files are stateless modules consumed by feature code; there is no import graph among them.
