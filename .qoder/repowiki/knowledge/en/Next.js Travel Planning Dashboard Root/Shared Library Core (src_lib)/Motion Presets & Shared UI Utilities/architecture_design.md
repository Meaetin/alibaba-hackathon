Two sibling sub-folders with no internal dependencies between them. `src/lib/motion/presets.ts` is a single file that centralizes design tokens (duration, easing) and composes them into reusable `Transition` and `Variants` objects (`motionTransitions`, `motionPresets`) consumed by motion/react components; it intentionally stays small so stateful choreography lives in callers while CSS tokens stay consistent. `src/lib/utils/` is a flat collection of independent, side-effect-free modules each exporting named helpers: `formatters.ts` (date/time/country-to-flag), `calendar.ts` (hour snapping, HHMM parse/format), `itinerary.ts` (time↔ISO conversion, activity mapping, date-range labels), `flightCard.ts` (maps persisted flight rows to `FlightCardProps` as the single source of truth across load/sync paths), `location-detail.ts` (opening-hours, price-range, stay-duration phrasing shared by itinerary panel and detail view), `scroll.ts` (finds nearest scrollable ancestor and scrolls to top), and `url-validation.ts` (URL schema validation). Modules only import from other utils or from higher-level app types (`@/lib/supabase/queries/home`, `@/components/ui/*`); there are no runtime imports between these utils files except `itinerary.ts` → `location-detail.ts`, keeping the graph acyclic and each file independently testable.
