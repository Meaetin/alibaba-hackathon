Flat collection of single-purpose utility modules with no runtime framework dependency beyond `google.maps` types. `place-search.ts` is the central module: it defines the normalized `PlaceSearchResult` / `PlaceDetailsPayload` shapes, composes `BASE_FIELDS` + `ENTERPRISE_EXTRAS` into a billing-aware `SEARCH_FIELDS` mask, and exposes `runPlaceSearch` (Text Search or Nearby Search driven by viewport), `fetchPlaceDetailsEnterprise` (lazy enrichment via Place Details), `normalizePlace`, `toPlaceDetailsPayload`, and `placeNeedsDetails`. `price-level.ts` is a shared dependency that normalizes both Maps JS (`MODERATE`) and REST (`PRICE_LEVEL_MODERATE`) strings into the canonical `PriceLevelOrdinal` type so browser and server agree on budget filtering; `price-range.ts` similarly flattens nested money ranges into a display-only `PriceRange`. `locality-pins.ts` groups saved locations by string-based `{region}, {country}` labels into `MapClusterData` clusters for static maps, explicitly separated from the planner's k-means geographic clustering. `location-row.ts` adapts persisted `ResolvedGoogleMapsLocation` rows back into `PlaceSearchResult` for the Add Location form. `google-maps-url.ts` is a tiny host-pattern validator for Google Maps share links. Dependency direction is one-way: `place-search.ts` imports `price-level.ts` and `price-range.ts`; other files depend on `place-search.ts` only via its exported types or `PlaceSearchResult` interface.
