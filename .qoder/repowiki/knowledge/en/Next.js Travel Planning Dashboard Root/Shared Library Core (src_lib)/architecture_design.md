The `src/lib` directory is a flat collection of feature-scoped sub-packages (`api`, `auth`, `errors`, `maps`, `motion`, `planner`, `query`, `supabase`, `utils`) plus root-level shared artifacts that act as the single source of truth for cross-child contracts. Children do not import each other directly; instead they depend on these root modules: `domain-types.ts` exports canonical enums (`Surface`, `ShareableEntity`, `QuotaType`) used by analytics, sharing, and quota logic across every child; `site.ts` exposes a single `SITE_URL` origin read from `NEXT_PUBLIC_SITE_URL`; `query/queryClient.ts` provides a globally configured TanStack Query client with default stale/gc times, while `query/queryKeys.ts` centralizes all cache key factories so `api_clients` and `supabase_layer` publish typed results into the same cache keyed consistently. Data-flow between children is indirect — e.g., `planner_engine` consumes place data produced by `maps`, and both `api_clients` and `supabase_layer` write to the shared React Query cache rather than holding state. Leaf utilities under `auth/password-policy.ts` and `errors/` are imported by multiple children without owning application state.
