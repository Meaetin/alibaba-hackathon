The root configures the build/runtime contract that all four sibling layers under `src/` share: `next.config.js` enables strict mode, image remote patterns for Supabase/Unsplash/ui-avatars, and optimized package imports; `tsconfig.json` maps `@/*` to `src/`; `vitest.config.ts` runs colocated tests with Vite path resolution. The layering is strictly top-down — `app_routes` (pages) import from `components_ui`, which consume `hooks_contexts` and `lib_core`; `lib_core` is the only layer that talks to Supabase or the external API, so cross-child communication flows through typed props, React Query cache, and the shared domain types rather than direct coupling. Environment variables are documented in `.env.local.example` and consumed via `NEXT_PUBLIC_*` across children.
