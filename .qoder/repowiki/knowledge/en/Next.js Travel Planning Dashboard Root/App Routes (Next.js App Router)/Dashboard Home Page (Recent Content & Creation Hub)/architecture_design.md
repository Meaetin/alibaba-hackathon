Built as a Next.js App Router route segment under `src/app/home/` with three files: `layout.tsx` wraps every child in the shared `MainLayout`, `loading.tsx` provides a skeleton mirroring the page layout for streaming suspense, and `page.tsx` is the client component (`"use client"`) that owns all dashboard state. The page composes reusable UI primitives from `@/components/ui` (cards, modals, skeletons) and orchestrates data via React Query hooks (`useProfileQuery`, `useLinkUsageQuery`, `useDashboardRecent`), a custom `useJobsQueue` hook for async content-analysis and itinerary-planning jobs, and `useMapClusters` for cluster-based location filtering. Cross-component communication uses a custom `argo:content-prepended` window event to prepend newly created items into the feed without a full refresh. Async jobs are surfaced inline as queue cards (`ItineraryQueueCardItem`) with optimistic handoff to real feed items once the server-side refresh lands. A mobile-only horizontal create carousel and a breakpoint-driven mobile content filter (`all | link | collection | itinerary`) adapt the same card list to small screens. Data mutations go through typed API helpers in `@/lib/api/*` (collections, itineraries, content, Supabase queries) and invalidation is coordinated via `queryClient.invalidateQueries` keyed by `queryKeys.*`. Heavy components like `StaticMap` are loaded lazily via `next/dynamic` with `ssr: false`.
