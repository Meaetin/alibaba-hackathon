Each child directory under `src/app/` is a Next.js App Router segment defining its own `layout.tsx` (providing per-feature chrome such as navigation or headers) and `page.tsx` (the feature UI). Dynamic segments (`[id]`, `[token]`) are used uniformly to expose detail views and public share endpoints for links, collections, and itineraries. The root `layout.tsx` supplies the global app shell and CSS, while `globals.css` provides shared styles consumed by all children. Feature pages consume shared data hooks and job queues defined outside this scope rather than embedding business logic.
