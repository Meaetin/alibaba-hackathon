Each file in this directory exports one or more self-contained presentational components that wrap `@base-ui/react` primitives (Button, Menu, Popover, Dialog/Sheet, Field) to add the application's design-system styling. Styling is centralized per component via `class-variance-authority` (`cva`) variant definitions (e.g. `buttonVariants`, `menuVariants`, `inputVariants`, `sheetVariants`) which declare `variant`, `size`, `icon`, `type`, and other axes with `defaultVariants` and `compoundVariants`. Components are client-side only (`"use client"`) and compose through a shared `cn` utility from `@/lib/utils` for conditional class merging. Cross-component composition is used where appropriate — e.g. `Input.tsx` composes `Menu`/`MenuContent`/`MenuItem` to implement a `DropdownSelector`, and `Sheet.tsx` reuses the same `Dialog` primitive as modals. Complex components expose multiple sub-components (e.g. `Menu` + `MenuTrigger` + `MenuContent` + `MenuItem` + `DescriptiveMenuItem` + `MenuSeparator`; `Popover` + `PopoverTrigger` + `PopoverContent`) following a Root/Trigger/Content pattern consistent with Base UI. All components forward refs, set `displayName`, and export both the component function and its corresponding `*Props` TypeScript interface.
