Two parallel entry points serve different map modes, both lazy-loaded via `next/dynamic({ ssr: false })` and deferred until in-viewport via `useIntersectionObserver`.

- Detail mode: `MapContainer.tsx` is the public facade consumed by pages; it renders a loading placeholder until visible then mounts `GoogleMapDetail`. `GoogleMapDetail.tsx` wraps everything in an `APIProvider`, renders a `Map` with `gestureHandling` toggled by `interactive`, and hosts three internal controller sub-components scoped inside `<Map>` so they can call `useMap()`: `MapBoundsController` (auto-fit bounds / single-location pan), `MapSearchController` (runs `runPlaceSearch` against the live viewport when `searchRequest.nonce` changes, using refs to avoid unstable callback re-runs), and `MapSearchRunnerProvider` (exposes a `PlaceSearchRunner` to parent pages once the Places library loads). Route polylines are drawn as paired `Polyline`s (white casing + colored overlay) and stop pins use either a custom SVG `StopPin` (numbered, day-colored teardrop) or the default pin image. Hover affordances switch between the rich `LocationHoverDetailsPopup` and the lightweight `MapNameBubble` based on `hoverVariant`.
- Cluster mode: `StaticMap.tsx` is the cluster-only entry point; it tracks its own `hoveredClusterId` state and lazy-mounts `GoogleMapCluster`. `GoogleMapCluster.tsx` computes auto center/zoom from cluster bounds via `calculateMapView`, renders each cluster as an `AdvancedMarker` wrapping `MapClusterMarker`, and optionally shows zoom controls via `MapControl`.
- Marker styling: `MapClusterMarker.tsx` and `MapMarkerHover.tsx` define `cva` variant maps keyed on `variant` (`by Country` | `by Collection` | `by Location`), `size` (`Small` | `Medium`), and `state` (`Default` | `Hover` | `Active`), composed with `cn` for final class strings.

Dependency direction is one-way outward: this module depends on shared UI primitives (`cn`, `next-themes`), calendar palette utilities (`getDayPalette`, `PALETTE_COLORS`), and the `@/lib/maps/place-search` API; it exposes typed contracts (`MapLocation`, `MapPolylineSegment`, `MapClusterData`, `GoogleMapDetailProps`) so consumers never touch the Google SDK directly.
