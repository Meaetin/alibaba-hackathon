The module is organized around a shared `BaseCard` shell (`BaseCard.tsx`) that owns the card layout, hover/selection styling, keyboard navigation, optional `next/link` wrapping with prefetching, and the trailing kebab `CardActionMenu`. All entity-specific cards (`ItineraryCard`, `LocationCard`, `LinkCard`, `CollectionCard`) are thin wrappers that compose `BaseCard` with a fixed `cardClass` (e.g. `itinerary-card`, `location-card`) and an `iconVariant` for the `CategoryBadge`. Media rendering is abstracted into `CardMedia.tsx`, which provides image/gradient/placeholder fallbacks and accepts a `children` slot so `CollectionCard` can inject its custom `CollectionImageGrid` multi-image grid. `RecentCard` is a standalone compact component that reuses `CollectionImageGrid` and maps a `type` discriminator to typed hrefs via `TYPE_HREFS`. A single `constants.ts` exports Tailwind-compatible class strings (e.g. `LINK_CARD_GRID_ROWS`) because dynamic interpolation would not generate CSS. Dependency direction is one-way: concrete cards → `BaseCard` + `CardMedia`; `RecentCard` additionally depends on `CollectionCard`'s grid helper.
