The module groups three client-side React components that sit at the application root. `QueryProvider.tsx` wraps the app in TanStack Query's `QueryClientProvider`, injecting a shared `queryClient` from `@/lib/query/queryClient`. `ThemeProvider.tsx` wraps the app in `next-themes`'s `NextThemesProvider` with class-based theming forced to light mode and transitions disabled. `notifications/ItineraryJobNotifier.tsx` is a no-op UI component (`return null`) that subscribes to Supabase Realtime `postgres_changes` on the `jobs` table filtered by user and type `itinerary-planning`; it tracks per-job status in an in-memory map, invalidates cached queries via `queryKeys.itineraries/upcomingItineraries/itineraryUsage`, and surfaces success/failure through `useToast()`. Dependency direction is one-way: providers depend only on external libraries and shared libs; the notifier depends on both the query client (for cache invalidation) and the toast context, but nothing depends back on these components.
