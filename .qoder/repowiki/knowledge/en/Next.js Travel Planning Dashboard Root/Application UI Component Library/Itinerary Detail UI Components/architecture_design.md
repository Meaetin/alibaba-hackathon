The module is organized as a flat collection of React client components plus two focused sub-packages. The `tabs/` sub-package provides one component per itinerary section (Bookings, Expenses, Flight, Lodging, Notes) that compose shared sidebar/detail-view primitives from the parent directory. The `ItineraryDayColumn/` sub-package encapsulates day-sequence logic and constants used by both the edit-mode column (`ItineraryEditDayColumn.tsx`) and the compact view (`CompactDayColumn.tsx`). Shared cross-cutting concerns—drag-and-drop helpers (`drag-utils.ts`), activity rendering (`activity-utils.ts`, `ActivityThumbnail.tsx`, `CompactActivityCard.tsx`), time-bar rendering (`TimeBar.tsx`, `DayTimePicker.tsx`), overlap detection (`overlap-utils.ts`), opening-hours status (`opening-hours-status.ts`), and map/search panels (`ItineraryMapSection.tsx`, `LocationDetailPanel.tsx`, `MapSearchBar.tsx`, `PlaceDetailsBlock.tsx`)—are consumed uniformly by both the main layout components (`ItineraryPageHeader.tsx`, `ItineraryControls.tsx`, `ItineraryEditLayout.tsx`, `ItinerarySidePanel.tsx`, `ItineraryTabBar.tsx`) and the tabs, keeping each tab lightweight and stateless while the parent components own routing, editing mode, and data flow.
