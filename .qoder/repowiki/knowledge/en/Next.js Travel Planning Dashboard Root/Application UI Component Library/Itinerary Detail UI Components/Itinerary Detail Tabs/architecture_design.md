Each file in this leaf module is a single-purpose client-side React component (`"use client"`) representing one tab of the itinerary detail page. The tabs are organized as parallel siblings — `BookingsTab`, `ExpensesTab`, `FlightTab`, `LodgingTab`, `NotesTab` — each exporting a named function component with a typed props interface. They compose higher-level UI from sibling packages under `@/components/ui/detail-views/*` (e.g., `FlightSidebar`, `LodgingSidebar`, `ExpensesSidebar`, `NotesGrid`, `FilePillHeader`) rather than implementing list rendering themselves; the tabs act as thin layout shells that pass data and callbacks down. `BookingsTab` currently renders a placeholder empty state, while `FlightTab` and `LodgingTab` additionally support an optional `FilePillHeader` for file attachments. All tabs accept an optional `className` prop and mark their root element with a `data-slot="*-tab"` attribute for test targeting. Styling is done via Tailwind classes composed through the shared `cn` utility from `@/lib/utils`.
